# 🎹 琴房小幫手 Piano Buddy

給準備表演曲目的鋼琴學習者的練習 Web App：**短時間也能有效練、知道兩次上課之間該練什麼、看得到離表演還有多遠。**

🔗 **線上使用**：https://albertani0410.github.io/piano-buddy/

> 第一次打開可以到「🎼 曲目」或「🤖 教練」按 **🧪 載入示範資料**，立刻看到教練的分析效果。

## 功能

| 分頁 | 功能 |
|---|---|
| 🎵 節拍器 | 40–208 BPM、Tap Tempo、2/4・3/4・4/4・6/8、重拍高音＋畫面閃爍、速度術語 |
| 🪜 速度階梯 | 從慢速開始，連續彈對 N 次自動加速；與節拍器、曲目進度連動 |
| ⏱ 練習 | 分段計時（每段可設小目標）、快速範本、提示音，練習時間自動記錄 |
| 📅 打卡 | 月曆熱度圖、🔥 連續天數、本週總分鐘，可手動補登 |
| 🎼 曲目 | 表演倒數、段落五階段熟練度（讀譜 → 分手 → 合手慢速 → 原速 → 可演出） |
| 🤖 教練 | 紅黃綠燈判斷「來不來得及」、推薦最弱段落的練法、一鍵排成今天的練習；可選用 Gemini API 取得 AI 建議 |

## 技術

- 單一 `index.html`（HTML / CSS / JavaScript），無需後端
- Web Audio API 產生節拍與提示音、Screen Wake Lock 防止螢幕休眠
- 資料存在瀏覽器 `localStorage`；AI 模式的 API Key 只存在使用者本機

## 修改紀錄

- **v1**：完成節拍器、分段練習、打卡日曆、曲目進度、規則式教練＋選用 AI 教練
- **v1.1**：修正「結束練習」等按鈕在內嵌預覽中無反應 → 改用自製確認框
- **v2**：新增速度階梯（與節拍器、曲目進度連動）
- **v2.1**：階梯卡片移到開始按鈕下方，手機不用捲動
